# OW勝率ボード

オーバーウォッチ公式「ヒーロー統計」から、ライバル・プレイの勝率を取得して表示するボードです。
GitHub Actions で毎週自動更新し、GitHub Pages で公開します。PCを起動しておく必要はありません。

- 取得条件（固定）：ライバル・プレイ／マウス＆キーボード／アジア／全ティア
- 自動更新：毎週水曜 3:00（日本時間）※GitHubの混雑状況により数分〜数十分遅れることがあります
- 手動更新：Actions 画面の「Run workflow」ボタン（管理者用URLで開いたボード下部の「今すぐ更新（手動）」から開けます）
- 管理者用URL：ボードのURLの末尾に `?admin` を付けると、下部に管理者ログイン欄が出ます（例：`https://<ユーザー名>.github.io/<リポジトリ名>/?admin`）。パスワードでログインすると「今すぐ更新（手動）」「おすすめを編集」のリンクが表示されます。閲覧者に共有するのは `?admin` なしのURLにしてください
- 先週分は1世代だけ保存し、前週比（+1.2／−0.8）を表示します。前回の更新から20時間以内の再実行では先週分は入れ替えません
- ※前週比は、アップデート等は考慮しないものとします

## ファイル構成

| ファイル | 役割 |
|---|---|
| `docs/index.html` | 表示ページ（GitHub Pages で公開） |
| `docs/data/stats.json` | 取得データ（自動・手動更新で書き換わる。手で編集しない） |
| `docs/data/recs.json` | 制作者のおすすめ（マップ×ロール）。ここを編集する |
| `scripts/fetch.mjs` | 取得プログラム（Node.js 20、追加パッケージ不要） |
| `.github/workflows/update.yml` | 自動更新（毎週水曜3時）と手動更新の設定 |

## 最初の設定（1回だけ）

1. GitHub で **公開（Public）** の新しいリポジトリを作る（例：`ow-winrate-board`）
2. このフォルダの中身をすべてアップロードする
   - ブラウザの場合：リポジトリの「Add file」→「Upload files」に、フォルダの中身をドラッグ＆ドロップ
   - `.github` フォルダも必ず含めてください（隠しフォルダなので見落としやすいです）
3. 「Settings」→「Pages」で、Source を「Deploy from a branch」、Branch を `main`・フォルダを `/docs` にして Save
4. 「Settings」→「Actions」→「General」→「Workflow permissions」で「Read and write permissions」を選んで Save
5. 「Actions」タブ →「OW勝率データ更新」→「Run workflow」で1回手動実行し、緑のチェックになることを確認
6. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でボードが表示されます
7. 管理者パスワードを設定する
   - `https://<ユーザー名>.github.io/<リポジトリ名>/?admin` を開くと、下部に「パスワードが未設定です」と出ます
   - 設定したいパスワード（8文字以上）を2回入力し「設定用の文字列を作る」を押すと、`const ADMIN_HASH = "…";` という1行が表示されます
   - GitHub で `docs/index.html` を編集し、`const ADMIN_HASH = "";` の行をその1行に置き換えて保存します
   - 1〜2分後に `?admin` を開き直すと、ログイン欄が出ます。ログインはブラウザのタブを閉じるまで有効です

## 管理者ログインについて

- ページに保存されるのはパスワードそのものではなく、元に戻せない変換（ハッシュ）をかけた文字列です
- ただし公開ページの仕組み上、ログインは「管理者用リンクを隠すため」のものです。実際の更新・編集はGitHub側で持ち主しかできないので、閲覧者がログイン画面を突破しても操作はできません
- 推測されにくいよう、他で使っていないパスワードにしてください
- パスワードを変えたいときは、`const ADMIN_HASH = "…";` を `""` に戻して保存し、手順7をやり直します

## おすすめの書き方

`docs/data/recs.json` を GitHub 上で開き、鉛筆アイコン（Edit）から編集して「Commit changes」で保存します。
管理者用URL（末尾に `?admin`）で開いたボード下部の「おすすめを編集」からも開けます。編集できるのはリポジトリの持ち主だけです。

```json
"busan": {
  "_map": "BUSAN",
  "tank": "ウィンストンで高台を取りやすい",
  "damage": "",
  "support": ["1行目", "2行目"]
}
```

- `""` の中に文章を書きます。改行したいときは `["1行目", "2行目"]` のように並べます
- `_map` はマップ名の目印なので変更不要です
- 保存後、1〜2分でボードに反映されます

## うまく動かないとき

- Actions が赤い×になった：ログの「失敗：」の行に理由が出ます。取得や検証に失敗したときはデータを書き換えないので、前回のデータが表示されたままになります
- 公式サイトが GitHub からのアクセスを受け付けない場合は、取得方法の変更が必要です
- リポジトリに60日間更新がないと定期実行が止まる仕様がありますが、毎週データ更新のコミットが入るため通常は止まりません
